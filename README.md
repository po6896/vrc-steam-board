# vrc-steam-board

VRChat ワールドの掲示板向けに、Steam の同時接続数・週間ランキング・売れ筋・セール・新作・ウィッシュリスト上位を 4 ページの画像にまとめて毎日公開します。

- `https://po6896.github.io/vrc-steam-board/board.png` 2048x2048、1024x1024 のページを 2x2 に配置
- `data.json` 同じ内容の文字データ / `history.json` 日ごとの同時接続数

データは Steam Web API と Steam ストアの公開情報から取得しています。Steam は Valve Corporation の商標です。本リポジトリは Valve と無関係の非公式のものです。
